> 适用：你登录飞牛桌面用的是**另外的网址和端口**（域名 + 自定义端口 / DDNS / 自建反代），希望浏览器插件也只记这一个地址，不想单独记 `IP:8765`。

## 一、先明确三个地址不是一回事

| 地址 | 例子 | 用途 | 鉴权 |
| --- | --- | --- | --- |
| 统一网关应用入口 | `https://nas.example.com:9443/app/edge-bookmarks` | 桌面 Web 管理界面 | 飞牛 NAS 登录会话 + 应用账号密码 |
| TCP 直连 | `http://192.0.2.10:8765` | 插件同步 API | Bearer 会话令牌 |
| **反代 API 路径（本页要配的）** | `https://nas.example.com:9443/eb-api` | 插件同步 API | Bearer 会话令牌 |

**插件不能直接用 `/app/edge-bookmarks` 作为稳定通道**：飞牛统一网关在把请求转发给应用**之前**就校验 NAS 登录会话，插件只有在该浏览器已登录飞牛桌面时才能复用 Cookie；未登录时请求到不了服务端，也没有任何「免登录路径」开关。

反代路径是**你自己加的一条独立 location**，它绕开应用网关鉴权，直接转发到 `127.0.0.1:8765`，因此插件可以用它。三个地址指向同一份 SQLite 数据。

## 二、前提

1. 已安装 `python312` 运行时，8765 在 fnOS 防火墙里被放行（`config/resource` 的 `port-config` + `EdgeBookmarks.sc`）。
2. 你能在「统一登录地址」对应的 Web 入口上加一条路径规则（飞牛自带反向代理、Lucky、Nginx Proxy Manager、自建 Nginx 均可）。
3. 规则必须挂在**不经过飞牛应用网关登录校验**的 server/location 上。若你的统一登录地址就是 fnOS 系统自带的 HTTPS 入口，其 Nginx 配置由系统管理，建议改用独立反代服务（另一个端口）来承载这条路径。

## 三、两种反代写法（任选其一）

假设反代路径统一用 `/eb-api`，后端是 NAS 本机的 `127.0.0.1:8765`。

### 模式 A — 保留前缀转发（最简，零配置，推荐先试）

`proxy_pass` **不带结尾斜杠**，路径 `/eb-api/api/v1/health` 原样转发给后端。服务端会自动识别第一段为外部前缀并在页面 `<base>` 里补回，**不需要任何环境变量或自定义请求头**。

```nginx
location /eb-api/ {
    proxy_pass http://127.0.0.1:8765;          # 注意：结尾没有 /
    proxy_http_version 1.1;
    proxy_set_header Host                $host;
    proxy_set_header X-Forwarded-For    $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto  $scheme;
    proxy_set_header Authorization      $http_authorization;   # 透传 Bearer 令牌
    proxy_read_timeout 60s;
}
```

### 模式 B — 剥离前缀转发（标准做法）

`proxy_pass` **带结尾斜杠**，反代把 `/eb-api/api/v1/health` 变成 `/api/v1/health`。此时必须追加 `X-Forwarded-Prefix`，否则前端资源与接口会打到域名根路径而 404。

```nginx
location /eb-api/ {
    proxy_pass http://127.0.0.1:8765/;         # 结尾有 /，剥离 /eb-api/
    proxy_http_version 1.1;
    proxy_set_header Host                 $host;
    proxy_set_header X-Forwarded-Prefix   /eb-api;   # 关键：页面基址
    proxy_set_header X-Forwarded-For     $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto   $scheme;
    proxy_set_header Authorization       $http_authorization;
    proxy_read_timeout 60s;
}
```

> `X-Forwarded-Prefix` 会被服务端严格校验（只允许 `/` + 字母数字 `-_.~`，拒绝 `..`、尖括号、引号），因此不能用来注入 HTML。
>
> 如果反代 UI 不支持自定义请求头，用**模式 A**。
>
> 高级用法：也可设置环境变量 `EB_PROXY_PREFIXES=/eb-api,/another`（逗号分隔）显式声明前缀，但不推荐——FPK 里改环境变量需要动 `cmd/main`，升级会被覆盖。

## 四、让 Web 界面生成正确的插件地址

连接卡片是只读的，**没有反代路径输入框**。正确做法：

1. 配好反代后，**直接用反代地址打开管理页**，例如 `https://nas.example.com:9443/eb-api/`。
2. 服务端按当前访问地址自动推算，`serverUrl` 会变成 `https://nas.example.com:9443/eb-api`，该路径同时进入候选池。
3. 点「**复制插件配置**」，粘贴到插件设置页的「① 粘贴插件配置」，再填「② 密码」即可，无需手工填写路径。

如需在不通过反代地址打开管理页的情况下让 `/eb-api` 进入候选，可设置 `EB_PROXY_PREFIXES=/eb-api`（见第三节高级用法）。

插件的 `normalizeServerUrl()` **保留路径前缀**（不会再把它裁成 origin），非标端口也照常保留；Chrome 的 `http://*/*` / `https://*/*` 权限匹配所有端口。

插件按「上次可用 → 主地址 → 备用地址 → 其余候选」探测，失败时错误信息会**逐条列出实际请求的 URL 与原因**。

## 五、验证

在**电脑**上执行（换成你的真实地址）：

```bash
curl -i https://nas.example.com:9443/eb-api/api/v1/health
```

期望：

```json
{"ok":true,"app":"edge-bookmarks","version":"1.4.0","base":"/eb-api/","channel":"direct", ...}
```

`base` 必须是 `/eb-api/`（模式 B 缺 `X-Forwarded-Prefix` 时会是 `/`）。再打开 `https://nas.example.com:9443/eb-api/`，应看到管理界面且样式正常。

插件点「测试连接」会显示实际命中的地址，例如：

```
连接成功 · 主地址 https://nas.example.com:9443/eb-api · 服务端 v1.4.0
```

## 六、排障

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| `curl` 返回飞牛登录页 / 302 | 规则落在应用网关后面，被登录校验拦了 | 把 location 放到独立 server，或改用单独端口的反代服务 |
| 404 | location 路径与插件填的不一致 | 两边都用同一个 `/eb-api`；注意结尾斜杠 |
| health 200 但页面样式全丢 | 模式 B 漏了 `X-Forwarded-Prefix` | 补头，或改用模式 A |
| 插件提示「返回非 JSON」 | 反代把请求转到了飞牛系统页面 | 检查 `proxy_pass` 目标与尾斜杠 |
| 插件提示「连接超时」 | 8765 不通 / 防火墙 / 应用未运行 | 见 [部署指南](部署指南.md) 与 [点开无反应排查](点开无反应排查.md) |
| 401 | 反代没透传 `Authorization` | 加 `proxy_set_header Authorization $http_authorization;` |
| HTTPS 自签证书 | 插件 fetch 会失败 | 先在对应浏览器里访问一次该地址并信任证书，或换受信任证书 |
| 误填了 `/app/...` | 网关前置鉴权 | 插件会给出针对性提示，改用反代路径或 `IP:8765` |

## 七、安全边界

- 反代路径**不绕过业务鉴权**：`/api/v1/*` 除 health 外仍需 Bearer 会话令牌（或 Basic 账号密码）；删除用户另需管理员权限。
- 服务端业务鉴权不依赖 `X-Trim-*` 身份头，伪造它们不会获得权限。
- `Authorization` 在 HTTPS 下传输；不要在没有令牌的 HTTP 公网上暴露写接口。
- 反代路径可以只给插件用，不必在飞牛桌面建图标。
